Reuse the gitja checkout instead of cloning it again

gitja is itself one of the repos listed in config.dhall, so it needs to
exist as a sibling checkout (../gitja) same as every other listed repo.
It was being fetched twice - once via actions/checkout to build the gitja
binary, then again via a fresh git clone in the sibling-repos loop. Move
the already-checked-out gitja-src into place instead of re-cloning it.
