      6

     10 ## default keybindings for all filetypes
     11 
     12 <F9> send visual selection (visual mode)
     13 <F9> send current paragraph (normal mode)
     14 <F8> send current line
     15 <F7> send word under cursor
     16 <F4> send section delimited by double comment characters
