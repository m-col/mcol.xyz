Add `desk X corner resize` option, colouring view corners when mod held

This is the first in a 2-step process. This commit results in corners
being drawn on views with a configured colour when the mod key is held
down. The next step is implemented server-side resizing enabled by
starting drags within these highlighted corner regions.
