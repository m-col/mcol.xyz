Convert config-reading logic into client-message parsing

Configuration is now done via client interface `wimptool` over socket
IPC. All mention of config files is and the example script has been
converted. Currently all IPC messages go directly into configuration
processing, but future work will also funnel message parsing into
actions that require remote data (e.g. select viewport using slurp), and
any subscriptions (e.g. programs that want to listen to state changes).
