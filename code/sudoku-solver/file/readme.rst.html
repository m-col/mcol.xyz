      1 sudoku-solver
      2 =============
      3 
      4 This small Haskell script solves sudoku puzzles. I wrote this as part of a
      5 programming exercise.
      6 
      7 The puzzle in ``puzzle_1.txt`` is in the public domain, and is taken from
      8 Wikipedia.
      9 
     10 Usage
     11 -----
     12 
     13 The script uses ``runhaskell`` as an interpreter but doesn't use any third
     14 party libraries.
     15 
     16 ./sudoku.hs puzzle_1.txt
     17 ./sudoku.hs  # Defaults to puzzle_1.text
     18 
     19 Where the file passed contains a sudoku puzzle encoded in spaces and digits,
     20 ignoring all other characters including newlines etc. The script extracts the
     21 digits and spaces and maps those onto the puzzle grid.
