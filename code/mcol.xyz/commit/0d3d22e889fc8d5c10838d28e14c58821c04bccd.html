Use actions/checkout for gitja and stop duplicating the repo list

- Check out gitja itself via actions/checkout (repository:/path:) instead
  of a raw git clone, matching how the workflow checks out everything else.
- Split the repo list out of config.dhall into gitja/repos.dhall, which
  config.dhall now imports. The workflow's clone step parses repos.dhall
  directly instead of carrying its own hardcoded copy of the list, so
  adding/removing/renaming a repo is a one-file change.
