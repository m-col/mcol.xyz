Parse repos.dhall with dhall-to-json instead of grep

grep against Dhall's text format is brittle (breaks on reformatting,
comments, etc). dhall-to-json is the real parser - pin a specific release
(1.42.2/dhall-json 1.7.12, verified against the actual x86_64-linux
tarball layout, which has no wrapping directory) and pipe its output
through jq to get the plain repo names, same as gitja's own stack.yaml.lock
pinning for reproducibility.
