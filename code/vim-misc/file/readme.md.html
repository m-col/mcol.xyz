      1 To install:
      2 
      3     git clone https://github.com/m-col/vim-misc ~/.vim/pack/vim-misc
      4     mv $HOME/.tmux.conf $HOME/.tmux.conf.backup
      5     echo "source ~/.vim/pack/vim-misc/tmux.conf" > ~/.tmux.conf
      6     mkdir -p $HOME/.vim/{backups,sessions,swap,undo,spell}
      7     git -C ~/.vim/pack/vim-misc submodule init
      8     git -C ~/.vim/pack/vim-misc submodule update --remote
      9 
     10 To update git submodule plugins:
     11 
     12     git -C ~/.vim/pack/vim-misc submodule update --remote
     13 
     14 To add a new git-backed plugin:
     15 
     16     git submodule add <url of git repository> start/<plugin name>
     17 
     18 To remove a plugin:
