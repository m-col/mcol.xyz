Use full clones for every repo gitja processes

Deploy failed with:
  gitja: BackendError "Could not lookup a71abc9ffbe3c7acb8092561daf4f1454499a2d7: Object not found - failed to find pack entry"

gitja walks each repo's full commit history unconditionally, but libgit2
(which it uses via gitlib/hlibgit2) doesn't respect git's shallow-clone
boundary the way native git does, so it tries to dereference a parent
commit that a shallow clone never actually fetched. Every checkout gitja
touches needs full history: the main mcol.xyz checkout (was the default
1-commit shallow fetch), the gitja checkout used to build the binary
(same repo also appears in the /code repo list), and the sibling repos
(were `--depth 100`).
