      1 hacking on Qtile: painting complex borders
      2 ==========================================
      3 
      4 :date: 2020-05-12
      5 :summary: Extending Qtile to create funky window border decorations
      6 
      7 The years of checking up on the unixporn subreddit has imprinted in me a want
      8 for a unique and aesthetic desktop. One of the advantages I saw in the Qtile
      9 window manager (while I was rapidly hopping between WMs) is how easy it is to
     10 bend to my will, being made in Python. Recently I set out to satisfy my desire
     11 for more than just single colour, single line window borders.
     12 
     13 The result of this endeavour has two parts. The first is a PR_ I submitted last
     14 week to Qtile that lets users pass their layouts a list of border colours and a
     15 list of border widths to paint multiple borders on their windows. In my head it
     16 was a long time coming, having nice windows like these:
     17 
     18 .. raw:: html
     19 
     20     <img style="box-shadow: 10px 10px 5px black;" alt="Window with triple borders" src="/static/qtile_multi.png"/>
     21 
     22 The code accepts any number of border colours and widths, so if you *really*
     23 wanted to, you could have borders like these:
     24 
     25 .. raw:: html
     26 
     27     <img style="box-shadow: 10px 10px 5px black;" alt="Window with a shitload of borders" src="/static/qtile_multi2.png"/>
     28 
     29 
     30 Has user freedom come too far?
     31 
     32 The PR also aimed to unify all border-drawing code into one callable. This
     33 leads to the second development: you can override this callable -
     34 :code:`xcbq.Window.paint_borders` of Qtile's X11 backend  - and replace the
     35 border-painting logic with your wildest dreams.
     36 
     37 Normally, this method would loop over the configured colours and widths, using
     38 them to draw increasingly small filled rectangles centred on a pixmap that will
     39 be used to paint the window's borders. This results in the multi-border effect
     40 above. A function we define to override this method will therefore have access
     41 to a list of colours, as well as the window's geometry including border width,
     42 and a canvas - the pixmap.
     43 
     44 The paintbrush is tycho0's xcffib_, which provides Python bindings to XCB_. The
     45 :code:`xcffib.xproto` module gives us the functions we need to create some
     46 shapes and paint them to our pixmap, which are reminiscent of their C
     47 counterparts such as :code:`xcb_poly_fill_rectangle` from xcb.xproto.h.
     48 
     49 Using this information, we can do whatever we want. A simple example would be
     50 to draw a couple of trapeziums (trapezia_? thefreedictionary suggests either,
     51 TIL) using :code:`xcffib.xproto.POINT` and paint them using and
     52 :code:`FillPoly` in two of the colours. This can create this picture frame-like
     53 appearance:
     54 
     55 .. raw:: html
     56 
     57     <img style="box-shadow: 10px 10px 5px black;" alt="Window with frame" src="/static/qtile_frame.png"/>
     58 
     59 Pretty cool, no? Maybe too simple.
     60 
     61 With some faffing around in GIMP on a screenshot of the `Common Desktop
     62 Environment`_ (CDE), I decoded the design for their old-school 3D borders. I'm
     63 aware I could have hunted down the source code to find out how their borders
     64 are drawn but where's the fun in that?
     65 
     66 The design is largely made of 1-pixel-wide lines, so we can use
     67 :code:`xcffib.xproto.POINT` as before to join them up, then :code:`PolyLine` to
     68 paint them to the pixmap. With a main colour, a lighter shade and a darker
     69 shade, we can get this result:
     70 
     71 .. raw:: html
     72 
     73     <img style="box-shadow: 10px 10px 5px black;" alt="Window with triple borders" src="/static/qtile_cde.png"/>
     74 
     75 Pretty groovy borders if you ask me, and it's a design I can use without
     76 sacrificing a solid, modern window manager.
     77 
     78 I've added these to my Qtile plugin repository qtools_, from which they can be
     79 used by simply importing and enabling the borders plugin with the desired
     80 style:
     81 
     82 .. code-block:: python
     83 
     84    import qtools.borders
     85    borders.enable("CDE")
     86 
     87 The plugins might also serve as a simple starting point to implement more
     88 border designs.
     89 
     90 I'd love to make a small library of different designs that can be used to make
     91 borders but my own creativity is limited. Let me know if you have any design
     92 ideas that you'd want implemented for your own Qtile config!
     93
