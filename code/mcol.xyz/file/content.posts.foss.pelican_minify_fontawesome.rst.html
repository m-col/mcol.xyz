      1 minifying font awesome in pelican
      2 =================================
      3 
      4 :date: 2019-10-20
      5 :summary: Minifying font awesome fonts and CSS in pelican state site generator
      6 
      7 I recently incorporated `font awesome <https://fontawesome.com/>`_ glyphs into
      8 my website in an attempt to add a touch more :fas:`eye` :fas:`candy-cane`. I
      9 wanted to self-host them, rather than use a CDN, for the slight privacy
     10 benefit.
     11 
     12 Following installation, I found the generation of my site, done by `pelican
     13 <https://blog.getpelican.com/>`_, was taking significantly longer. Perhaps I'm
     14 crazy, but I also felt like Firefox was loading the pages for a noticably
     15 longer few milliseconds and the change wasn't doing anything for the
     16 perfectionist in me.
     17 
     18 Looking at the files I had just bundled with my pages, they had added at least
     19 200KB in webfonts (possibly more, depending on which filetype is requested) and
     20 around 55KB in CSS to my website. And for what, the odd glyph here or there?
     21 Most of my blog posts are less than 10KB, as is the rest of my CSS, so I
     22 determined to find a solution to incorporate only those glyphs that I wanted to
     23 use.
     24 
     25 creating a pelican pugin
     26 ------------------------
     27 
     28 The `documention
     29 <https://docs.getpelican.com/en/stable/plugins.html#how-to-create-plugins>`_
     30 for creating pelican plugins is useful, but I found reading existing plugins in
     31 the `great repository <https://github.com/getpelican/pelican-plugins>`_ of
     32 plugins much more informative.
     33 
     34 Eventually I had put together a plugin that (so far!) appears to work wonders:
     35 `pelican-minify-fontawesome
     36 </code/pelican-minify-fontawesome>`_ :fas:`grin-beam`.
     37 
     38 First, after site generation, it identifies which font awesome icons are
     39 present by scanning the output folder and getting all HTML class attributes
     40 that start with :code:`fa-`. The words that follow this string are the names of
     41 the icons.
     42 
     43 With a bit of regex magic, these icon names are then used to extract their
     44 corresponding CSS blocks from a locally available font awesome download. These
     45 CSS blocks are then copied into the output folder.
     46 
     47 Extracting the glyphs from the fonts was the tricky part. FontForge advertised
     48 Python bindings, so guided by `their docs
     49 <https://fontforge.github.io/python.html>`_ I tried to put the logic together.
     50 FontForge's approach to manipulating fonts did take me a while to understand,
     51 however it does work well. This is the gist of it:
     52 
     53 .. code-block:: python
     54 
     55    font = fontforge.open(font_path)
     56    selected = False
     57    for icon in icons:  # The list of icon names
     58        try:
     59            font.selection.select(("more",), icon)
     60            selected = True
     61        except ValueError:
     62            # icon not found in font
     63            pass
     64 
     65    if selected:
     66        font.selection.invert()
     67        font.clear()
     68        font.generate(output_path)
     69 
     70 One by one, it loads each font, :code:`select`\s our desired icons that are
     71 present in the font, and, if there are any, it inverts the selection and
     72 deletes it. This leaves only our desired icons in the font, which is saved into
     73 our output folder.
     74 
     75 adding font awesome RST roles
     76 -----------------------------
     77 
     78 I wanted to add something extra for convenience, that is reStructuredText roles
     79 that allow me to include font awesome fonts inline in my posts.
     80 
     81 I added 3 roles: :code:`fas`, :code:`far`, and :code:`fab` for font awesome's
     82 solid, regular and brands icon lists. These can be used like this:
     83 
     84 .. code-block:: RST
     85 
     86    Here is the classic :fas:`blender-phone`.
     87 
     88 Here is the classic :fas:`blender-phone`.  
     89 
     90 result
     91 ------
     92 
     93 Whenever I use a new icon, like the :fas:`poo-storm`, I simply use one of the
     94 above RST roles in my draft and then pelican will include it when it copies
     95 over font awesome's CSS and webfonts into the output folder.
